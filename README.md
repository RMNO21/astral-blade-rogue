# Astral Blade - Webcam Gesture Arcade Game 🎮⚡

یک بازی وب‌کم فوق‌العاده روان، ریسپانسیو و جذاب در سبک آرکید/بقا (Endless Survival) که با هوش مصنوعی و بینایی ماشین (MediaPipe Hands) کنترل می‌شود.

## ویژگی‌ها ✨
- **کنترل با دست و وب‌کم**: تشخیص دست و فیلتر لرزش با فیلتر One-Euro برای حرکت کاملاً نرم.
- **سیستم هوشمند تفکیک دو دست (Dual-Hand Priority)**: اولویت‌بندی خودکار دست متحرک به عنوان دست اصلی و فیلتر کردن دست ساکن بدون پرش یا تداخل.
- **مکانیک موج شوک و انجماد (Shockwave & Freeze)**:
  - با باز بودن دست: حرکت آزادانه در صفحه.
  - با مشت کردن یا پینچ دست: توقف کامل کاراکتر (Freeze) و شارژ موج پالس ضربتی.
  - پالس شوک، تیرهای دشمن را بازتاب داده و دشمنان مجاور را به طور کامل متلاشی می‌کند.
- **سیستم آنتی‌کمپ (Anti-Camping Cooldown)**: شارژ اولین پالس سریع (کمتر از ۰.۵ ثانیه) است و در دفعات متوالی زمان شارژ بیشتر می‌شود، مگر اینکه ۱ ثانیه با دست باز حرکت کنید تا ریست شود.
- **حالت بی‌پایان رکوردی (Endless Mode)**: ثبت بالاترین رکورد (High Score) در حافظه محلی مرورگر همراه با افزایش تدریجی و متوازن درجه سختی.
- **رابط کاربری و منوی تعاملی فارسی**: هاد سایبرپانکی، نشانگر سلامت، دوربین بندانگشتی زنده (PIP) با برچسب‌های فارسی وضعیت دست.

## اجرا به صورت لوکال 🚀

1. نصب وابستگی‌ها:
```bash
npm install
```

2. اجرای سرور توسعه:
```bash
npm run dev
```

3. مرورگر را باز کرده و به آدرس نمایش داده شده (معمولاً `http://localhost:5173`) بروید و دسترسی دوربین را تأیید کنید.
